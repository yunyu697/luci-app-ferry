# r14：独立可选面板包（zashboard 3.22.0）+ 只读拦截 + 卸载还原

r14 的主包功能保持向后兼容，新增一个**完全独立、可选安装**的包 `luci-app-ferry-dashboard`；主包侧只增加了「按面板开关注入/不注入」的能力，不装面板包时主包不产生任何面板端点。

## 新增：面板独立可选包

- 包名 `luci-app-ferry-dashboard`，版本 `1.0.0-r14`，依赖 `luci-app-ferry`，**不并入主包**；不装该包时主包不产生任何端点（无菜单、无 rpcd、无静态资源、无 9090 监听、无防火墙表）。
- 面板固定 zashboard **3.22.0**（`dist-no-fonts.zip`，MIT，许可证全文随包放在 `/usr/share/licenses/luci-app-ferry-dashboard/`），静态资源放 `/www/luci-static/ferry-dashboard/`。
- 只读两层：仓库内可复核补丁 `dashboard/patches/zashboard-3.22.0-readonly.patch`（只注入 shim 引用）+ 运行时 `ferry-readonly.js` 对 `fetch`/`XMLHttpRequest`/`WebSocket` 做方法白名单。
  - 拦截（403）：`PATCH /configs`、`PUT /configs?reload=true`、`POST /restart`、`POST /upgrade*`、`PUT /providers/*`、`DELETE /connections`
  - 放行：全部 `GET`、`PUT /proxies/{group}`（切换节点）、`WS /traffic`
- 安全边界（实跑实测）：监听 `192.168.1.1:9090`（只绑 LAN IPv4，不绑 `0.0.0.0`）；secret 由 `/dev/urandom` 生成 32 hex，落盘 `/etc/ferry/panel.secret` 权限 `0600`（33 B 含换行），只注入生成的 mihomo `external-controller` / sing-box `experimental.clash_api`，不进包、不进静态文件；fw4 独立表 `ip ferry_panel` 仅放行 `br-lan` 源 `192.168.1.0/24` 与 `lo` 到 9090，其余 drop。
- LuCI「面板」页：状态表（启用/内核/监听/注入/密钥/进程）、能力表、页内打开（iframe）与新标签打开；sing-box 下不可用能力置灰并给出文字说明。
- 卸载（`opkg remove` / `apk del`）完全回到安装前状态：删 UCI、删 secret、撤 nft 表、重启当前内核让注入消失、删除面板独占的空目录与许可证目录，并剥离**非当前内核**配置里本次注入的 secret 块（只匹配本次 secret，不误伤订阅/自备配置）。

## 三项代价（必须如实说明）

1. **包体增量：解包后 +5,665,328 B（约 +5.4 MiB / +5.6 MB）**，共 51 个文件；ipk 约 2.9 MB、apk 约 2.9 MB。**16 MB flash 设备请只装主包**（主包 r14 ipk 约 116 KB）。
2. **版本升级耦合：zashboard 钉死 3.22.0**。上游自 3.23.0 起移除 sing-box 支持，一旦跟随升级，sing-box 用户会直接失去面板；因此**禁止升级到 3.23.0+**，升级前必须按 `docs/dashboard-proposal.md` §13 的复核清单重新验证两个内核。
3. **一次性只读补丁**：面板不是官方只读版，需要维护 `dashboard/patches/zashboard-3.22.0-readonly.patch` + 运行时 shim。上游换版要重新 rebase 补丁并重跑只读拦截测试（403/放行矩阵见下）。

## 主包改动

- `files/usr/lib/ferry/generate.sh`：按面板启用状态注入 mihomo `external-controller` / sing-box `clash_api`；未启用/未安装时完全不写。
- `files/usr/lib/ferry/common.sh`：新增面板状态/端口/secret 只读读取函数（不生成、不落盘）。
- `files/usr/bin/ferry-txnctl`：`status` 不再 `pm_load`，每次轮询省掉 `config_load` 与 2 次 `ip addr`。
- `files/usr/lib/ferry/transaction.sh`：tmp-off 日志引用已抓取的 nft 快照，避免重复 `nft list`。
- `files/usr/libexec/rpcd/luci-ferry-kernel`：快速方法同步执行，只有 `versions`/`mirror_test`/`start` 保留 watchdog。
- `kernel.js`：安装进度轮询 1s → 2s，并加 30 分钟上限；超时停止并提示「后端任务可能仍在继续，可点重试或刷新页面」。
- `safety.js`：安全页空闲轮询 1s → 10s（有 pending 时仍 1s）。

对应的行为代价（主包侧）：别的标签页/SSH 新建的 pending 在本页最多晚 10 秒出现（本页自身保存会整页刷新，不受影响）；超过 30 分钟的任务需要手动刷新才继续看进度。

## 已知问题 / 未验证

- **未在真实硬件（含 16 MB flash 设备）验证**：空间占用、内存、长时间运行均为 QEMU 结果。
- **apk（25.12）侧只做了包结构与校验**，未在 apk 设备上做安装/卸载实跑。
- 未做长时间 WebSocket 稳定性、多用户并发、低内存设备压测。
- zashboard 3.22 的 sing-box「即将移除支持」上游提示是否仍会弹出，本轮**未单独断言**；只读拦截与「规则」入口隐藏已实测。
- opkg 卸载会打印 `file_sha256sum_alloc: Failed to open file /etc/config/ferry-dashboard`：prerm 主动删 conffile 以避免残留，卸载结果正确，该行为 opkg 噪声。
- 浏览器验证经宿主机 `hostfwd` 访问 guest；iframe 的 `hostname` 在宿主侧替换为 `127.0.0.1`，其它参数（端口、secret、`type=clash`、`kernel`）与真实 URL 一致。
- ipk 内嵌 gzip 时间戳，同一源码两次构建字节数可相差 1–3 B、SHA-256 不同；apk 的文件 mtime 固定为 `1600000000`，包体大小由内容决定。以 Release 附件 `SHA256SUMS` 为准。
