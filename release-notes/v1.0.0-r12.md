# r12：CI 首次接入（构建、离线回归、自动发布）

本轮代码内容就是 CI 本身，内核与前端功能与 r11 一致。

## 新增

- `.github/workflows/ci.yml`（push `main` / PR / `workflow_dispatch`）
  - `shellcheck`：仓库内全部 shell 脚本，`--severity=error --format=gcc`，输出 `文件:行:列`，有 error 即红；未使用 `|| true`。同时修复了 `files/usr/bin/ferry-diag` 中被 shellcheck 判为 error 的数组展开写法（`$k[` → `${k}[`）。
  - `frontend-contract`：`node --check` 全部 LuCI `resources/view/ferry/*.js` 与 `resources/ferry/*.js`；跑 `tests/test-luci-contract.mjs`（类加载器契约）与 `tests/test-kernel-ui-errors.mjs`（r11 进度/错误态静态断言）。
  - `offline-tests`：`test-generate / test-rules / test-diag / test-mgmt-bypass / test-transaction / test-uninstall / test-kernel / test-sysupgrade / test-firewall / test-dnsmasq` 逐个执行，任一失败即 job 失败。`test-kernel.sh` 支持用 `KSRC` 指向 CI 拉取的真实内核归档（仅测试夹具）。
  - `packages`：构建 ipk + apk，`verify-pkgs.sh` 解包后与 `files/` 做 `diff -r` / 逐文件比较、文件数一致、ipk `Version` 与 apk `version` 都等于 `PKG_VERSION-rPKG_RELEASE`；产物作为 artifact `luci-app-ferry-packages` 上传。
- `.github/workflows/release.yml`（tag `v*`）
  - `guard`：tag 必须等于 Makefile 的 `v<PKG_VERSION>-r<PKG_RELEASE>`（apk pkgver 由同一值派生），且 `release-notes/<tag>.md` 必须存在，否则直接失败，不发空正文。
  - `checks`：`uses: ./.github/workflows/ci.yml` 复用全部 CI 检查与出包。
  - `publish`：下载 CI artifact → 本地再次校验包内容 → `gh release create` 上传 ipk/apk/`SHA256SUMS` → 重新 `gh release download` 并 `sha256sum -c`，不一致即失败。
  - `concurrency: release-<tag>` 且 `cancel-in-progress: false`，同版本重复触发不会互相覆盖。
- `scripts/ci/`：`stage.sh`、`build_ipk.py`、`build-pkgs.sh`、`verify-pkgs.sh`、`fetch-apk-tools.sh`（Alpine v3.23 静态 apk-tools，Ubuntu 无需 root/Docker）、`fetch-kernel-fixtures.sh`、`check-version.sh`、`shellcheck.sh`，以及包内 `post-install.sh` / `pre-deinstall.sh`。

## 修复

- 并发回滚的锁竞争：`pt_claim` 在锁目录刚建立、`ts` 尚未落盘的瞬间会读到空值并当成“陈旧锁”，并发时第二个进程可能抢走新锁，导致同一事务被回滚两次（历史重复、UCI 反复还原）。改为用锁目录 `mtime` 兜底判断。该问题由 `test-transaction.sh` 的并发回滚断言在 CI 上暴露。

## CI 覆盖 / 不覆盖

覆盖：shell 静态检查、前端语法与契约、10 个离线回归套件、ipk/apk 出包与逐文件一致性、tag 与版本一致性、Release 自动创建与附件哈希复核。

不覆盖（工作流注释中已写明）：

- QEMU OpenWrt guest 安装/升级矩阵、真实内核下载、WebUI headless CDP 断言（`tests/luci-dom-negative.sh`、`ui/cdp-kernel-ui.mjs`）。
- 真机 opkg/apk 安装与运行、代理链路与端口连通性。
- 真实公网下载与镜像回退（r11 的真机下载使用本地 1:1 HTTPS 镜像）。
- 25.12 apk 在 guest 实跑：本轮仍只有离线回归 + 出包校验，未在 25.12 guest 安装。
- 非 x86_64 架构。

## 产物

由 tag 触发的 release job 自动构建并上传，哈希见 Release 附件 `SHA256SUMS`。
